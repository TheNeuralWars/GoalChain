# Instrucciones de Lanzamiento - Hermes en Virtuals.io

## Pasos para lanzar

1. **Revisar metadata**
   - Archivo: `metadata.json`
   - Ajustar imagen, precio y supply según decisión final

2. **Preparar assets visuales**
   - Crear imagen del agente (recomendado 1024x1024)
   - Crear banner para la página de GoalChain

3. **Configurar treasury**
   - Crear wallet o smart contract para recibir revenue
   - Definir cómo se distribuye el 30% al Vault

4. **Subir a Virtuals.io**
   - Usar el dashboard de Virtuals para crear el agente
   - Cargar `metadata.json`

5. **Anunciar**
   - Publicar en Discord/Telegram
   - Notificar a holders de Genesis Squad
   - Crear página en goalchain.fun/agents/hermes
