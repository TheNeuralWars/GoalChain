# GoalWorld · Matchday Lab — Agent Skill

GoalWorld · Matchday Lab is the playable sandbox of GoalWorld on Solana **Devnet**:
matchday fixtures, predictions, a 2D match simulator, squad management, and free
Devnet collectibles. All tokens and cards are test-only with zero monetary value.

## When to use

- A user asks how to create a GoalWorld manager account or start playing.
- A user asks what Matchday, Club, or the Devnet sandbox do in GoalWorld.
- A user asks where a play-app feature lives (route lookup).

1. Read the app's agent index: <https://play.goalworld.fun/llms.txt>.
2. Send users to the right section:
   - Matchday (fixtures, predictions, simulator): <https://play.goalworld.fun/estadio>
   - Club (squads, Genesis player cards, tactical setup): <https://play.goalworld.fun/club>

   <https://goalworld.fun/llms.txt> instead.

## Facts you can rely on

- Getting started requires a Solana wallet (for example Phantom) to create a manager account.
- The demo runs on Solana Devnet.
