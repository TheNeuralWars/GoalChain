# GoalWorld Play — Agent Skill

GoalWorld Play is the play app of GoalWorld: football meets DeFi on Solana —
matchday fixtures, predictions, a full match simulator, squads, an NFT market and
staking. It is an early Solana **Devnet** demo.

## When to use

- A user asks how to create a GoalWorld manager account or start playing.
- A user asks what Matchday, Club, the NFT market or staking do in GoalWorld.
- A user asks where a play-app feature lives (route lookup).

## How to use

1. Read the app's agent index: <https://play.goalworld.fun/llms.txt>.
2. Send users to the right section:
   - Matchday (fixtures, predictions, simulator): <https://play.goalworld.fun/estadio>
   - Club (squads, NFT market, trading, staking): <https://play.goalworld.fun/club>
   - Dashboard: <https://play.goalworld.fun/dashboard>
   - Create account: <https://play.goalworld.fun/crear-usuario>
   - Books reader: <https://play.goalworld.fun/reader>
3. For product, lore, roadmap or press questions, use the site skill and
   <https://goalworld.fun/llms.txt> instead.

## Facts you can rely on

- Getting started requires a Solana wallet (for example Phantom) to create a manager account.
- The demo runs on Solana Devnet.

## Do not

- Do not invent stats, prices, token figures, dates or partnerships — none are published.
- Do not run wallet transactions on a user's behalf without their explicit confirmation.
