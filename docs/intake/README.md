# GoalChain intake queue

Structured briefs from **Hermes** (or you) before any agent implements code.

## Create a brief

Copy `TEMPLATE.md` to `YYYY-MM-DD-short-slug.md`, fill all sections, set `Status: ready`, assign **one** implementer (usually Cursor).

## Rules

- No implementation starts without `ready` + assigned owner.
- Chat/Slack messages are not source of truth — this folder (or a GitHub issue) is.
- See `ai_context/AGENT_ORCHESTRATION.md` for the full multi-agent workflow.
