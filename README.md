# ⚽ GoalChain: The Web3 World Cup Revolution

GoalChain es una plataforma integral de entretenimiento futbolístico en la blockchain de Solana, diseñada para el Mundial 2026. Combina coleccionismo NFT, un simulador de penales 1vs1 y una economía circular sostenible.

## 🚀 Componentes del Proyecto

### 1. 🖼️ Genesis Squad NFT Collection
Una colección masiva de **1,248 jugadores** de las 48 selecciones del Mundial.
- **Utilidad:** Cada NFT genera "sueldos" en $GCH basados en el desempeño real de los jugadores.
- **Rarezas:** Mythic, Legendary, Epic, Rare, Common.
- **Ecosistema:** Sistema de apertura de sobres (Pack Opening) y Mercado de Alquiler.

### 2. 🎰 Penalty Betting (1vs1)
Un mini-juego interactivo donde los usuarios apuestan tokens $GCH o NFTs en duelos de penales.
- **Tax Deflacionario:** 10% de comisión (5% Dev / 5% Jackpot).
- **Integración:** Lógica de apuestas conectada a la billetera del usuario.

### 3. 💎 Economía Sostenible ($GCH)
Basada en el [Economic Blueprint](./ECONOMIC_BLUEPRINT.md).
- **Circularidad:** Ganancias por partido ➔ Reinversión en salud/stats ➔ Quema de tokens.
- **Jackpot:** Un bote acumulado para los holders de las selecciones ganadoras.
