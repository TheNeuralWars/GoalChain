# Antigravity Customizations Export

To import these custom skills and MCP configurations on another machine:

1. Locate or create the configuration folder:
   `~/.gemini/config/`
   *(Usually `/Users/<username>/.gemini/config/`)*

2. Copy the `plugins` folder and `mcp_config.json` file from this package into `~/.gemini/config/`.

3. Restart Antigravity. It should automatically discover the new skills and configuration!
